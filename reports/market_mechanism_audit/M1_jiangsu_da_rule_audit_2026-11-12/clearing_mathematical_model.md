## 2. Episode 结构（**本阶段最重要的待裁决项**）

### 2.1 三个选项

| 选项 | 结构 | 策略在决策时看到什么 | 与 D-002 的一致性 |
| --- | --- | --- | --- |
| **P0 现状** | 24 个 4 时段滚动窗口顺序决策，块内执行前 4 段 | 已实现的 LMP、自己的历史动作 | **不一致**：这是日内滚动市场 |
| **P1 纯日前** | 每日 **一次** 决策，提交 96 时段完整申报 | 仅 D-1 10:30 前可得的信息 | **一致** |
| **P2 参数化日前** | 每日 **一次** 决策，输出一组申报参数，由冻结的 quote map 展开为 96 时段曲线 | 同 P1 | **一致**（表达力受限） |

### 2.2 结论

**P0 必须废弃。** 日前市场的定义是 D-1 一次性申报（R-03、R-19）：
策略在看到任何 D 日价格之前就要提交全天 96 个时段。顺序决策 + 日内价格反馈属于日内滚动交易，
与 `10_DECISION_LOG.md` D-002 直接冲突。

P1 与 P2 的区别只是 **动作参数化**，不是市场结构。建议采用 **P2**，理由：

1. 动作维度可控（P1 的完整申报是 96 × 2 条曲线，维度上千）；
2. 学习目标是"报价策略"，不是"逐点调度表"；
3. 表达力的损失可以量化并声明（见 §3.3）。

**代价（必须写进报告）**：P2 的可达申报集是规则允许集的 **子集**。
任何"学习到的策略优于/劣于基准"的结论，都只在该子集内成立。

## 3. 96 时段日前申报模型

### 3.1 申报对象

对每个储能单元 $k$、每个时段 $t \in \{1,\dots,96\}$，提交两条曲线：

$$
\text{充电申报 } C_{k,t}:\ [0, P^{c}_k] \to [0, p^{\max}], \qquad
\text{放电申报 } D_{k,t}:\ [0, P^{d}_k] \to [0, p^{\max}]
$$

均为 **单调非递减阶梯函数**（R-44），$p^{\max} = 1500$ CNY/MWh（R-45）。

曲线用 $S$ 段表达，段 $s$ 的宽度 $w_{k,t,s}$、价格 $\pi_{k,t,s}$：

$$
\sum_{s=1}^{S} w_{k,t,s} = P^{c}_k \ (\text{或 } P^{d}_k),\quad
w_{k,t,s} \ge 0.1\ \text{MW 的整数倍},\quad
0 \le \pi_{k,t,1} \le \pi_{k,t,2} \le \cdots \le \pi_{k,t,S} \le 1500 .
$$

端点约束（R-44）：第一段起点 $0$、第一段终点 $\ge 0.25 P_k$；末段终点 $= P_k$。

**本项目的 $S$**：$P_k = 0.4$ MW、最小步长 0.1 MW → 每方向至多 **4 段**（工程推论，非规则原文）。

### 3.2 与现状的差别

| 项 | 现状 | 本方案 |
| --- | --- | --- |
| 申报对象 | 两个标量（`charge_price`,`discharge_price`） | 每个时段两条阶梯曲线 |
| 功率轴 | 无 | 有，端点与步长受约束 |
| 价格区间 | 0–150 / 0–300 | 0–1500 |
| 真值点 | 箱的下边界 (0,0)，只能加价 | 由策略输出的曲线本身决定；"诚实报价"是其中一点，不是边界 |
| 时间维度 | 每块覆盖 4 段 | 全天 96 段同时提交 |

### 3.3 动作参数化（建议）

**建议：两结点曲线族，每个方向两个价格参数，共 4 个/单元/日。**

$$
\pi^{c}_{k,t}(q) = a^{c}_{k,t} + (b^{c}_{k,t} - a^{c}_{k,t})\,\frac{q}{P_k},\qquad 0 \le a \le b \le 1500
$$

单调性由构造保证，4 个 0.1 MW 段由线性插值 + 步长取整恢复。

**可选的时间形状**：若允许各时段不同，令 $a_{k,t} = \alpha_k + \beta_k\,g_t$，
其中 $g_t$ 为 D-1 可得的公开信号（如归一化负荷预测形状），则每个方向只需 2 个参数。

**表达力声明**：两结点单调族 **不能** 表达非线性的分段策略（例如"低段极低、高段极高"的陡峭曲线）。
若研究需要这种形状，须换更宽的族，并在报告中重新声明可达集。

## 4. 配电网集中出清模型

### 4.1 集合与索引

$t \in \{1..96\}$ 时段，$i \in \mathcal B$（33 母线），$l \in \mathcal L$（辐射线路），
$k \in \mathcal K$（4 台储能），$a \in \mathcal A$（负荷），$r \in \mathcal R$（风光）。
$dt = 0.25$ h。$b_0$ 为 PCC 母线。

### 4.2 变量

| 变量 | 含义 | 界 |
| --- | --- | --- |
| $q^{c}_{k,t,s},\,q^{d}_{k,t,s}$ | 第 $s$ 段的充/放电中标功率 | $[0, w_{k,t,s}]$ |
| $c_{k,t} = \sum_s q^{c}_{k,t,s}$，$d_{k,t} = \sum_s q^{d}_{k,t,s}$ | 实际充/放电功率 | $[0, P_k]$ |
| $e_{k,t}$ | SOC | $[0.10, 0.90]$ |
| $u_{a,t},\,x_{a,t}$ | 已供 / 未供负荷 | $\ge 0$ |
| $g_{r,t}$ | 风光实际使用 | $\ge 0$ |
| $v_{i,t},\,I_{l,t}^{2}$ | 电压平方、电流平方 | $v \in [0.93^2, 1.05^2]$，$I^2 \ge 0$ |
| $P_{l,t},\,Q_{l,t}$ | 线路潮流 | 自由 |
| $p^{\text{grid}}_t$ | PCC 净注入 | $[-2.5, +\infty)$ MW |

### 4.3 目标函数（最大化）

$$
\max\ \sum_{t} dt\Big[
\underbrace{\sum_{a} U_a(u_{a,t})}_{\text{需求价值}}
-\underbrace{\sum_{a}\pi^{u} x_{a,t}}_{\text{失负荷罚}}
-\underbrace{\sum_{k}\sum_{s}\pi^{c}_{k,t,s} q^{c}_{k,t,s}}_{\text{充电申报成本}}
+\underbrace{\sum_{k}\sum_{s}\pi^{d}_{k,t,s} q^{d}_{k,t,s}}_{\text{放电申报收入}}
-\underbrace{w_t\, p^{\text{grid}}_t}_{\text{PCC 购电成本}}\Big]
$$

**四条与现状的结构性差别，每条都是一个独立的设计主张：**

1. **没有循环成本项。** 退化成本是参与者自己的成本，应当体现在它提交的报价曲线里，
   而不是由出清器替参与者记账。`[假设]`
2. **没有时段折扣 $\gamma^t$。** 日前市场在一个决策时刻提交全天申报，日内没有"折现"的经济含义。`[假设]`
3. **没有期末库存估值项。** 市场只对申报出清；库存价值是参与者自己的判断，见 §9。`[假设]`
4. **目标里没有碳/绿电/弃电项。** 与现配置一致（均未启用），不需要额外处理。`[简化]`

### 4.4 约束

| # | 约束 | 形式 |
| --- | --- | --- |
| C1 | PCC 电压 | $v_{b_0,t} = 1$ |
| C2 | 节点有功平衡 | 潮流 + 注入 = 0（$p^{\text{grid}}$ 只出现在 $b_0$） |
| C3 | 节点无功平衡 | 同上 |
| C4 | DistFlow 压降 | $v_{\text{to}} = v_{\text{from}} - 2(rP + xQ) + (r^2+x^2)I^2$ |
| C5 | 二阶锥 | $P^2 + Q^2 \le v_{\text{from}} I^2$ |
| C6 | 线路容量 | $I^2 \le I_{\max}^2$ |
| C7 | 电压带 | $0.93 \le V \le 1.05$ |
| C8 | 风光上限 | $0 \le g_{r,t} \le \overline{g}_{r,t}$ |
| C9 | 负荷平衡 | $u_{a,t} + x_{a,t} = L_{a,t}$ |
| C10 | 储能功率 | $c_{k,t} \le P_k$，$d_{k,t} \le P_k$ |
| C11 | SOC 转移 | 见 §5 |
| C12 | PCC 交换 | $-2.5 \le p^{\text{grid}}_t$（进口无上限） |
| C13 | 段内顺序 | 不需要二进制：$\pi$ 单调非递减时，最优解不会跳过便宜段（标准 merit-order 论证） |

**平局规则**：LP 退化时可能出现无穷多最优解。建议显式规定"按申报段比例分配"，
与 R-25（同价按容量比例分配）方向一致，避免对偶随求解器随机变化。

## 5. 储能 SOC 跨时段约束

$$
e_{k,t+1} = e_{k,t}
+ \Big(\eta^{c}\, c_{k,t} - \frac{d_{k,t}}{\eta^{d}}\Big)\frac{dt}{E_k},
\qquad e_{k,1} = e^{0}_k = 0.50
$$

$$
0.10 \le e_{k,t} \le 0.90 ,\qquad
e_{k,97}\ \text{自由}
$$

- 效率 $\eta^c = \eta^d = 0.92$（宪章 §6）。
- $E_k = 1.6$ MWh，$P_k = 0.4$ MW → 满功率一小时改变 SOC $0.92 \times 0.4 / 1.6 = 0.23$。
- **日终 SOC 自由**（D-004）。这意味着没有末窗口可行性问题，也意味着
  **必须** 由 §9 的库存估值来约束"把电放光"的倾向。
- 跨日：$e_{k,1}$ 每日重置为 0.50，不承接前一日 $e_{k,97}$（D-003）。

**同时充放电**：C10 允许 $c$ 与 $d$ 同时为正。若目标系数不含退化成本，
在没有套利价差时 $c=d=0$ 最优；但在负价或阻塞情形下可能同时为正。
建议保留"净功率"重构（`net = d - c`）或在 $c,d$ 上直接施加互斥，
**二选一必须在 M2 前定**，因为它影响对偶与非凸性。

## 6. PCC 外部价格边界与定价机制

### 6.1 边界

$$
p^{\text{grid}}_t \in [-2.5,\ +\infty)\ \text{MW},\qquad
\text{成本价 } w_t \ \text{（外生，CNY/MWh）}
$$

`[规则]` 的对应物：省间联络线与省内出清决定 PCC 处的边际价格（R-22、R-30 未直接规定配电侧，
故此项为 `[简化]`）。

### 6.2 一个必须正视的经济结论

在 **进口无上限、价格外生** 的边界下：

$$
\lambda_{t,b_0} = w_t \quad\text{（PCC 处）},\qquad
\lambda_{t,i} = w_t + \text{网损/阻塞分量}
$$

于是 **储能对 PCC 价格没有影响力**：它是价格接受者。策略的空间只剩两个来源：

1. **网络约束**：当储能所在母线或上游线路受限时，局部 LMP 才与 $w_t$ 分离，储能的申报才影响自己被结算的价格；
2. **信息与库存**：报价反映对未来价格与自身库存的判断，不改变价格本身。

**如果 IEEE33 在任何运行点上都不绑定（电压与线路都不起作用），那么"报价策略"没有经济内容**——
在完全竞争下最优申报就是诚实申报，MATD3 学不到任何东西。

这是重构前必须先回答的问题：

> 本研究的"策略学习"发生在 **网络约束使储能成为局部边际单元** 的情形，
> 还是在 **储能能通过申报影响局部价格** 的情形？

若是前者，研究目标应改述为"配电网约束下的储能日前报价与运行"，
并明确"策略价值来自网络位置与库存判断，不来自市场力"。
若是后者，需要引入使储能成为关键单元的边界（例如 PCC 进口限值、分区限制、或本地市场机制），
而这些 **不是江苏日前规则的直接内容**，属于 `[假设]`。

**本条列入裁决项 Q-D3（见 `M1_decision_report.md`）。**

## 7. 节点价格计算

$$
\lambda_{t,i} = -\,\frac{\mu_{t,i}}{dt},
\qquad \mu_{t,i} = \text{节点有功平衡 C2 的对偶}
$$

与 R-29（节点边际电价 = 增加单位负荷导致的系统总电能供给成本增量）定义一致。

- **结算用价**：储能 $k$ 用其所在母线的 $\lambda_{t,\text{bus}(k)}$，不用跨母线平均值。
- **不得** 把 $\lambda$ 与 `price = lmp.mean(axis=1)` 混用；后者是旧 UI 的聚合量。
- **不得** 称 $\lambda$ 为"江苏节点电价"。

## 8. 日前结算模型

见 `settlement_spec.md`。此处只锁定一件事：

**结算按出清量 × 节点价格，不按申报价。** 申报价只决定"是否中标"和"中标多少"，
不决定"按什么价付钱"。这是"报价是价格、不是参数"的直接后果，也是与现状最大的经济差别
（现状的结算账本已经在用 LMP，但出清目标里同时用申报价作成本，两者混在同一目标里）。

## 9. 终端库存估值方案（D-004）

三个候选，均 **不进入出清目标**，只进入参与者自己的评价（奖励与报告）。

| 方案 | 定义 | 经济依据 | 可用性 |
| --- | --- | --- | --- |
| **O-A 影子价格法** | $v_T = $ 出清对偶中"再多 1 MWh 电量"的边际价值（SOC 转移约束的对偶） | 与市场同源，不是任选常数 | 需要读对偶；退化时不稳定 |
| **O-B 价格水平法** | $v_T = \hat\lambda$，即 D-1 可得的**历史价格水平**估计（本项目为价格曲线的日内在值域内的均值型统计量），并截断到 $[0,1500]$ | 库存的机会成本是"留到明天的电值多少钱"，其期望由价格水平决定 | **推荐**；数据可得 |
| **O-C 声明参数法** | $v_T$ 由策略自己申报，界 $[0,1500]$ | 上界有经济含义：能量不可能超过市场价格上限 | 可作为消融，不作主方案 |

**推荐 O-B**，理由：

1. 它只使用 D-1 可得信息，不泄漏当日价格；
2. 上界来自规则价格上限，不是拍脑袋的常数；
3. 它把"日终库存值多少"变成一个 **可陈述、可敏感性分析** 的量，而不是模型内部魔法。

**必须满足的报告纪律**：

- 奖励中库存项与现金项 **分开记录**：`cash_profit`、`inventory_value`、`degradation_cost`；
- 研究 KPI（`pi_ai`、`delta_pi` 等）**只在现金项上定义**；
- 任何"库存估值"数字 **不得** 出现在现金流、结算单或市场收入栏目中。

## 10. MATD3 接口建议

> 只是建议，不是实现。任何一项落地都需要新协议 ID 与新冻结清单（`.claude/rules/model_constraints.md`）。

### 10.1 Observation

原则：**只含 D-1 10:30 前可得的信息**。

| 类 | 候选特征 | 说明 |
| --- | --- | --- |
| 时间 | 时段索引、是否峰段 | 公开 |
| 负荷 | D-1 发布的负荷预测形状（归一化） | 若项目数据无 D-1 预测，则用历史同型日形状，并声明为 `[假设]` |
| 价格 | 历史已实现价格的水平与形状统计 | **不得**含当日价格 |
| 自身 | SOC_0、容量、效率、自身历史收益 | 私有 |
| 其他主体 | 历史申报统计 | **不得**含当日他方申报 |
| 市场 | 价格上下限 | 公开（R-20） |

**必须移除**：现状里的"本日已发生 LMP"类特征——它们在日前市场中不存在。

### 10.2 Action

建议 4 参数/单元/日（§3.3），可选扩展到 6–8 参数加入时间形状。

- 界 $[0,1500]$，单调性由参数化保证。
- **禁止** 把真值点设成箱的边界（现状 F1 的问题：策略只能加价）。
- 参数与"诚实申报"之间应存在可表达的双向偏移。

### 10.3 Reward

$$
r_k = \underbrace{\text{cash\_profit}_k}_{\text{结算现金}}
+ \underbrace{v_T\,(e_{k,T} - e_{k,0})\,E_k}_{\text{库存价值，单列}}
- \underbrace{\text{degradation}_k}_{\text{退化成本}}
$$

- 三项分开记录；KPI 只用第一项。
- 是否保留"相对诚实申报的差分奖励"（现有 B_C2 设计）属于独立设计选择，见 Q-D5。
- **奖励不是 payoff**（`.claude/rules/model_constraints.md`）。任何对外结论必须回到 `participant_payoff`。

## 3. Q3/Q4 储能充电、放电的申报要求与量价曲线字段

### 3.1 已取得的字段描述（`[S]`，V2.1 / 407号函 转发稿）

电网侧储能以场站为单位报量报价，申报交易信息主要包括 **D 日充电量价曲线和放电量价曲线（MW）**：

| 字段 | 取值 | 等级 |
| --- | --- | --- |
| 曲线条数 | 2 条：充电、放电 | `[S]` |
| 功率轴单位 | MW | `[S]` |
| 第一段起点 | 0 | `[S]` |
| 第一段终点 | 不低于 25% 额定充放电功率 | `[S]` |
| 最后一段终点 | 场站额定充放电功率 | `[S]` |
| 段间衔接 | 每段起点必须为上一段终点 | `[S]` |
| 单调性 | 报价曲线随出力增加**单调非递减** | `[S]` |
| 单段步长 | 不低于 **0.1 MW** | `[S]` |
| 价格区间 | 不得低于申报价格下限、不得高于上限 | `[S]` |
| 价格上下限 | **0 – 1500 CNY/MWh** | `[S]` |
| 段数上限 | **未在取得的文本中确认**（机组报价为最多 10 段，储能未核到） | **BLOCKED** |
| 是否需要申报 SOC 上下限 / 最小连续充放电时长 / 日末期望 SOC | **未在江苏文本中核到**（其他省份有此类字段，**不得套用**） | **BLOCKED** |

### 3.2 与机组报价的对比（`[P]`，仅作结构参照，不得套用到储能）

V1.0 第九十五条对 **发电机组** 规定：

- 电能量报价 **最多 10 段**；
- 每段申报出力区间起点（MW）、终点（MW）、区间报价（元/MWh）；
- 第一段起点为最小稳定技术出力，最后一段终点为额定有功功率；
- 每段起点 = 上一段终点；
- 报价曲线随出力增加 **单调非递减**；
- 每段步长 **不低于 1 MW**；
- 每段报价在申报价格上下限内。

**这条是机组规则，不是储能规则。** 二者的步长不同（1 MW vs 0.1 MW）、曲线不同（一条 vs 两条），
把机组字段直接套到储能上属于 `[T]` 级别的推断，本项目不采用。

### 3.3 结论

- 储能的 **曲线结构**（两条、单调非递减、端点与步长约束）**可以确定到字段级**，但来源是 `[S]` → **PARTIAL**。
- 储能的 **段数上限、SOC 类参数、申报时间** 未核到 → **BLOCKED**。
- **可实现的子集**：本项目可以实现"两条单调非递减量价曲线 + 0–1500 价格界 + 端点/步长约束"，
  但必须在报告中写明这是"按 V2.1 转发稿字段的可实现子集，非原文核对结果"。

机器可读版本见 `bid_schema_spec.json`。

补充（`[P]`）：

- 第七十条：D-1 日开展 D 日交易，每个自然日 **96 个交易出清时段（00:15–24:00）**，每 15 分钟一段。
- 第七十六条：D-1 09:30 前发布 D 日 96 点机组状态，发电企业 10:30 前确认；10:30 前申报出力上下限。
- 第七十八条：系统负荷预测与母线负荷预测均为 D 日 96 点。

**对本项目的含义**

- **策略的决策截止时刻 = D-1 10:30。** 在此时刻之后才产生的任何量（D 日出清价格、D 日实际负荷）
  都不能进入 D-1 申报策略的输入。这是 `data_information_timing_spec.md` 的硬约束。
- 预出清（11:00）、省间（11:30）、辅助服务（13:30）都在最终出清（14:30）之前，
  **本项目不建模这三步**，因为它们需要省间与华东市场数据。
- "缺省报价"机制 `[P]`：未申报时系统用缺省报价。本项目不建模缺省报价。

**是否可直接实现**：时序 **可以**（作为信息集边界）；出清算法 **不可**（见 §10）。

## 5. Q6 日前市场出清目标与约束（`[P]`，V1.0）

| 要素 | 官方表述 | 条款 |
| --- | --- | --- |
| 交易组织 | 报量报价；全电量竞价、集中优化 | 第六十九条 |
| 出清目标 | **社会福利最大化** | 第七十三条 |
| 出清算法 | 安全约束机组组合（SCUC）+ 安全约束经济调度（SCED） | 第七十三条 |
| 输入 | 系统负荷预测、母线负荷预测、区外来电、特殊机组出力曲线、检修安排、机组运行约束、电网运行约束 | 第七十三条 |
| 输出 | 机组开机组合、分时发电出力曲线、**分时分区电价** | 第七十三条 |
| 安全校核 | 电力平衡校核 + 安全稳定校核；不满足时调整边界并重新出清 | 第一百一十至一百一十四条 |
| 备用 | 全网/分区正负备用需求作为出清边界条件 | 第八十一条 |
| 新能源 | 新能源 D 日 96 点预测曲线优先出清 | 第八十条 |
| 同价分配 | 同一节点机组报价相同时，按该申报段容量的比例分配中标容量 | 第一百〇四条 |
| 必开机组 | 必开最小出力优先出清，**不作为定价机组** | 第一百〇五条 |
| SCUC 定义 | 以社会福利最大化或系统总电能供给成本最小化为目标，形成多时段开停机组合 | 第二十四条 |
| SCED 定义 | 以系统总电能供给成本最小化等为目标，形成多时段机组出力安排 | 第二十五条 |

**对本项目的含义**

- 官方出清目标是 **社会福利最大化**，不是"总购电成本最小"。本项目在配电网层的目标函数
  也应表述为同一族（需求价值 − 供给成本），而不是仿照现有实现的混合式（`clearing_objective`）。
- 官方出清是 **SCUC + SCED**，本项目 **没有机组**，只能做配电网层的 SCED 型（无开停机）。
  这不是同一模型，必须声明。
- **价格上下限** 是出清边界条件的一部分（第九十九条），不是事后裁剪。

## 6. Q7 中标量与节点价格的适用规则

| 概念 | 官方定义 | 条款 | 等级 |
| --- | --- | --- | --- |
| 节点边际电价 | 满足发电侧与输电安全约束下，为某一电气节点增加单位负荷导致的**系统总电能供给成本的增加量**；由系统边际电价、阻塞价格等构成 | 第十七条 | `[P]` |
| 系统边际电价 | 为参考母线增加单位负荷导致的系统总电能供给成本的增加量；参考母线处阻塞价格与网损价格均为零 | 第十八条 | `[P]` |
| 分区电价 | 电网存在输电阻塞时，按主要阻塞断面将市场分成几个价区 | 第二十三条 | `[P]` |
| 阻塞费用 | 等于两节点之间的电能量价格价差乘以电网潮流 | 第二十条 | `[P]` |
| 发布口径 | D-1 17:30 前发布"D 日分区、分时日前电能量出清价格" | 第一百一十五条 | `[P]` |

**对本项目的含义**

1. 官方 **对外发布** 的是 **分区、分时** 价格，不是 33 个配电节点价格。
2. 本项目计算的 `lmp[t,i]` 是 **配电网层节点边际价格的模型量**：
   - 它按第十七条的同一定义构造（节点平衡对偶）；
   - 但它的网络是 IEEE33 配电馈线，不是江苏输电网；
   - 因此 **不得** 称其为"江苏节点电价"或"江苏分区电价"。
3. 江苏 V2.2 是否改为节点定价结算，只有 `[T]` 支撑 → **BLOCKED**，本项目不据此改结论。

## 7. Q8 储能日前充电、放电的结算规则

### 7.1 V1.0 中可直接核对的部分（`[P]`）

| 规则 | 条款 |
| --- | --- |
| 现货市场每 **15 分钟** 为一个计量、结算时段；以日周期发布现货电量电费结果，以月周期发布正式结算依据并结算 | 第二百一十九条 |
| 中长期合约全电量结算；日前出清电量与中长期合同的偏差电量按 **日前分区电价** 结算；实际上网/用电量与日前出清电量的偏差按 **实时分区电价** 结算 | 第二百二十二条 |

| 必开必停机组按"日前出清价格或发电成本核定价格"取高者处理，增加成本计入成本补偿 | 第九十条 |

| 日前/实时双结算的储能具体公式 | `[T]` | V2.2 结算示例说明未取得 → **BLOCKED** |

### 7.3 本项目的可实现子集

在本研究框架内（只做日前、无中长期、无实时、无补偿费用），可实现的结算为：

```
储能 k 的日前电能量现金收益 = Σ_t dt · λ_{t, bus(k)} · (dis_{k,t} − ch_{k,t}) − 退化成本
```

其中 `λ` 为配电网层节点边际价格。这个式子的 **结构** 与第二百二十二条（日前出清量按日前价格结算）
和第二百二十四条（现货电费按出清量计价）一致，但：

- 它是 **研究者按通用条款构造的等值式**，不是江苏储能专项公式；
- **必须** 在 `settlement_spec.md` 中标注 `PROJECT_ASSUMPTION`；
- **不得** 写成"按江苏规则第 X 条储能按此结算"。

其它必须声明为 **不在模型内** 的费用：输配电价、上网环节线损、系统运行费、政府性基金及附加、
偏差电费、容量补偿、成本补偿、辅助服务、各类不平衡资金。

## 8. Q9/Q10 与 IEEE33 等值模型的差异、无法复现的部分

### 8.1 结构性差异

| 维度 | 江苏日前市场 | 本项目等值模型 | 性质 |
| --- | --- | --- | --- |
| 网络 | 省级输电网 + 220 kV 母线 | IEEE33 配电馈线 | 不同对象 |
| 出清 | SCUC + SCED（含开停机） | 无机组，配电网层 SCED 型 | 缺少开停机 |
| 主体 | 发电企业、一类用户、售电公司、电网侧储能、虚拟电厂、微电网 | 4 台储能（建模主体）+ 被动负荷与风光 | 主体稀少 |
| 价格 | 分区、分时日前出清价格 | 33 节点配电网 LMP | 不同对象 |
| 价格来源 | 省内出清内生 | PCC 外生价格曲线 + 网络内生化 | 价格主体过程不在模型内 |
| 结算 | 中长期 + 日前 + 实时 + 各类补偿与分摊 | 仅日前电能量 | 口径更窄 |
| 省间/辅助服务 | 11:30 / 13:30 两步，影响 14:30 出清 | 不建模 | 缺失边界条件 |

### 8.2 因缺少省级机组与输电网数据而 **无法复现** 的部分

1. **SCUC 的开停机组合**：无机组参数（最小稳定出力、启停费用、最小连续开停机时间）。
2. **系统边际电价**：参考母线在省级输电网，不在配电网。
3. **分区电价的价区划分**：需要主要阻塞断面与输电网潮流。
4. **阻塞费用**：需要输电网潮流与断面限额（第二十条）。
5. **系统/母线负荷预测的生成**：220 kV 母线节点负荷需求不在项目数据内。
6. **正负备用需求与备用约束**（第八十一条）。
7. **省间日前现货交易结果**（第一百〇一条）与 **华东调峰/备用辅助服务结果**（第一百〇二条）。
8. **机组必开必停、出力上下限、检修安排**（第八十六至八十九条）。
9. **新能源优先出清与全额保障性收购**（第八十条）。
10. **缺省报价机制**（第九十二条）。
11. **容量补偿、成本补偿、不平衡资金、辅助服务费用**（第二百二十四/二十五条）。
12. **申报/结算价格限值的动态调整**（第七十四条、第九十九条）。

### 8.3 因此本研究的科学边界

> 本研究不检验"江苏市场如何定价"，而是在 **给定的 PCC 价格场景 + 给定的配电网约束** 下，
> 检验储能日前报价策略的可学习性与网络影响。省级价格形成过程是输入，不是被解释对象。

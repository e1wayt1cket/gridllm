## 2. 明确排除

| 排除项 | 原因 | 若被引入会怎样 |
| --- | --- | --- |
| 实时市场与实时偏差结算 | 研究范围仅日前 | 收益口径变为两结算，KPI 不可比 |
| 实时调度 / 再调度 | 同上 | 引入当日执行信息，破坏 D-1 信息集 |
| 辅助服务、AGC 调频 | 范围外 | 需另行建模容量与调用规则 |
| 日内滚动交易、日内重新报价 | 与日前单次申报矛盾 | 使 Episode 不再是日前决策 |
| 中长期合约 | 无合约数据 | 结算公式不得引用不存在的合约电量 |
| 省间现货、华东调峰/备用 | 省级数据不可得 | 不可能在本等值模型中复现 |
| 容量补偿、成本补偿、不平衡资金 | 无省级机组与结算数据 | 不得补入，遗漏必须声明 |

**此表是硬边界。** 代码里现有的实时/滚动实现（`two_settlement`、`clear_rt_rolling`、滚动 MPC 窗口）不构成对它们的重新纳入。

## 4. 建模主体的资格假设

项目中的 4 台 0.4 MW / 1.6 MWh 储能是 **研究模型中的独立储能代理**。

- 江苏规则中可参与现货的是 **电网侧储能（以场站为单位报量报价）**，其准入条件（备案、直接接入公用电网、独立计量与控制、可被调度监控、法人资格）本项目 **未核实 4 台 0.4 MW 单元是否满足**。
- 因此：**"假定该储能已满足市场准入并可按模型报价提交日前申报"是算例假设，不是政策事实。**

该假设必须出现在任何论文、日志与图表标题中（或由其引用的假设清单承担）。

## 5. 价格数据的身份

项目现有江苏日前价格来自 `docs/日前价格261009.xlsx`，由 `dianyicha_price.read_curves` 读取：

- 四条曲线 **全部是空间均价**（`spatial_statistic: spatial_mean`），不是任何母线/分区/结算节点。
- 时间统计量各不相同：`261009` 为单日，`7days` / `30days` / `halfyear` 为 7 / 30 / 180 日窗口均值。
- **一天加三条窗口均值不构成逐日价格序列。**

因此：

- 可以用它们构造价格场景；
- **不得** 宣称基于真实逐日价格完成跨日训练、波动分析或泛化验证；
- **不得** 把任何一条曲线当作 D-1 时点可得的"预测"——它没有可核验的窗口结束日期。

## 6. 负荷数据

项目现有负荷为经过质量控制的江苏行业用户日负荷曲线，用于塑造 IEEE33 标准负荷的日内形状。

- 现有阶段只保证 **归一化形状** 与经审计的绝对功率口径；不得称其为"江苏实际负荷"。
- 负荷日与价格日不必同日（见 `reports/single_day_diagnostic_case.md`）。

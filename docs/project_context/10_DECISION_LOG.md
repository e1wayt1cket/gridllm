## D-003 交易日独立性

- **日期**：2026-11-12
- **决定**：每个交易日为一个独立 Episode，96 个 15 分钟时段；SOC 日内连续、跨日完全独立；
  每日初始 SOC 重置 0.5；不传递跨日 SOC、交易计划、结算状态或储能义务。
  MATD3 网络参数可跨日学习；Replay 可存多日经验但必须保留 Episode 边界。
- **来源**：用户口述（§二"交易日独立性"）
- **影响**：Episode 构造与管理规则，见 M1 的 `episode_independence_spec.md`。

## D-004 日终 SOC 不强制等于 0.5

- **日期**：2026-11-12
- **决定**：日终 SOC 不强制回到 0.5。终端库存价值必须 **有经济依据**；
  不得擅自设定任意残值；不得把库存估值伪装成市场现金收入。
- **来源**：用户口述（§二"交易日独立性"）
- **影响**：与冻结协议 `terminal_soc.final = 0.5` 冲突（见 `11_OPEN_ISSUES.md` I-02）。
  现金收益与库存价值必须分账报告。

## D-011 市场声明 2.5 MVAr 可控无功资产（母线 17/31/32）

- **日期**：2026-11-19
- **决定**：市场在建日时声明一个零有功出力的可控无功资产：母线 17 为 1.0 MVAr、
  31 为 0.5 MVAr、32 为 1.0 MVAr（`run_local_da.REACTIVE_SUPPORT_MVAR`），
  结构由 `local_da_contracts.condenser` 表达，`build_day` 与
  `local_da_days.window_day` 都携带它，并写入产物的 `context.reactive_support_mvar`。
  库文件、网络参数与负荷曲线不变；历史复现路径（`build_legacy_day`、
  `build_historical_day`）不携带该资产。
- **来源**：用户口述（"做1吧"，采纳筛选报告按可行性、价格尾部与松弛紧性排序的第一项）
- **影响**：v3 库 136 天全部可清出，不再需要按可行性剔除训练日或验证日
  （`excluded_days.json` 仅描述零能力屏幕）。该容量是在同一 136 天上测量选取的
  样本内参数，不是设备数据；无功在申报目标中无价格。残余：101 天仍触及 0.93、
  2 天触及 1.07、最差日markup 9.5x；2021-09-30 的锥间隙 8.5e-6 MW2 仍高于
  1e-6 探索性门槛。测量与等价性验证见
  `reports/candidate_days_v3_clearing_2026-11-17/RESULTS.md`。

## D-012 变电站进口上限 3.0 MW（项目假设）

- **日期**：2026-11-21
- **决定**：`local_da_contracts.GATEWAY_IMPORT_LIMIT_MW = 3.0`，作为
  `DayAheadInput.import_limit_mw` 的默认值。`run_local_da.build_day` 与
  `local_da_days.window_day` 都不传该字段，因此库日与训练窗口携带同一个上限；
  需要无上限的路径显式传 `None`（`src/s8_physical_audit.py` 已如此）。
  这是项目假设，不是江苏规则：3.0 MW 低于 IEEE33 基准自身的 3.715 MW 同时峰值。
- **来源**：用户口述（"设一个进口上限"），承接 M1 审计 Q-D3 的选项二：
  无上限时边际供给永远是对外购电，储能的报价无法触达任何价格。
- **影响**：改变了市场语义，因此 v7 现为 `NO_GO`——`local_da_contracts.py` 与
  `tests/test_local_da_market.py` 都是受 pin 的源文件，`code_sources_match`
  与 `code_tests_match` 转 false。恢复 GO 需要一次重新冻结：新候选 id 与配置哈希、
  在带上限的市场语义下重新生成 136 天鉴定证据、重新 finalize。到本次为止未做。
- **测量**（2021-12-07 全天窗口，零价参考报价；其余测量见
  `reports/audit_remediation_2026-11-15/IMPORT_CAP_MEASUREMENT.md`）：
  无上限时 `pcc_max` 4.466 MW，限值走廊（t=41..59，四台 ESS 母线）的 LMP
  均值在报价 0/150/300 下都是 38.25 CNY/MWh；上限 3.0 时 `pcc_max` 3.000，
  同一走廊的 LMP 均值分别为 327.38 / 203.80 / 76.84；上限 3.5 时为
  312.82 / 193.67 / 70.23。上限让报价进入价格，这是该决定的目的。
- **残余**：同一次改动把退化成本写进了出清目标（`ClearingModel` 的储能项现在
  对充、放两侧都计 `degradation_cny_mwh`，与结算一致），因此"真实报价"不再在
  任何抽样日是亏损：五天上限内/外的现金流由 −756…1039 变为 317…1273 CNY/日。
  剩下的是走廊里的买方垄断——储能是唯一弹性主体，它的补电估值就是走廊价格；
  在 2021-12-07 上限内，报价 100 比报价 0 多赚 238 CNY/日，是当前市场唯一
  真实的策略收益。其余八行抽样中真实报价即最优或差距在 1% 以内：
  这个市场接近"真实报价最优"，可学习空间很小，这是机制的性质，应报告而不是继续改。

## D-013 第二进口段：外部价格 + 250 CNY/MWh

- **日期**：2026-11-21
- **决定**：在上限之上再声明一段应急进口
  （`GATEWAY_EMERGENCY_IMPORT_MW = 1.0`），计价为外部价格加固定溢价
  `EMERGENCY_IMPORT_PREMIUM_CNY_MWH = 250.`（0.25 元/kWh）。两段合计 4.0 MW，
  高于 IEEE33 基准 3.715 MW 峰值。合同字段为 `DayAheadInput.import_emergency_mw`
  与 `emergency_import_premium_cny_mwh`；出清、定价、结算与物理审核都按
  "计划段 + 应急段"合计的物理进口计。两段都是项目假设，不是江苏规则。
- **来源**：用户口述（"0.25元/kWh"，回答"应急段溢价锚定多少"）。
- **影响**：改变了市场语义，v7 仍是 `NO_GO`，重新冻结未开始（同 D-012）。
  精确调度与连续定价模型的锥容差随之分开：精确 1e-9、定价 1e-8——
  第二段把精确模型的锥残留抬到 1e-5 审计界附近（2021-06-13 在 1e-8 下为
  1.04e-5），而连续模型在 1e-9 下返回 SUBOPTIMAL。
- **测量**（五天抽样，零价参考报价，见
  `reports/audit_remediation_2026-11-15/IMPORT_CAP_MEASUREMENT.md`）：
  储能申报数量为零时五天全部可出清（合计进口峰值 3.01–3.77 MW，均低于
  4.0 MW），不再出现"不报价即无解"；应急段实际只在 2021-06-13 与
  2022-08-01 的稀缺时段被调用（0.27 MWh、0–0.40 MWh），稀缺时段储能母线
  LMP 为约 295 与 351–357 CNY/MWh，Slack 处上限即 280 与 330
  （外部价格 + 250，储能母线再含网损边际）。放电报价 0/100/200/250/300
  的现金流在四天里以报价 0 最高；唯一正收益仍是 2021-12-07 的买方垄断
  （报价 100 比 0 多 238 CNY/日）。充电报价 0/50/100/150 同样单调递减。
- **残余**：结算按节点 LMP 支付充、放两侧，报价只改变中标量与时序、不改变
  单价，因此储能的最优报价就是参考真实点 (0, 0) 本身——两天抽样里
  `qualified_for_settlement` 为 true（SMOOTH_PASS）。第二段给出的是"稀缺有
  上限"，不是"加价有空间"；要让加价真正带来收益需要改支付规则（按申报价
  支付）或收紧应急段，二者都是机制决策，尚未做。

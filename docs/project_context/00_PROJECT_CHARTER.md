## 1. 研究目标

研究 **MATD3** 在 **江苏日前市场规则约束** 下，对 **IEEE33 配电网** 中 **储能资源日前竞价策略** 的学习作用。

四个固定要素：

| 要素 | 取值 |
| --- | --- |
| 网络 | IEEE 33 节点配电网 |
| 价格 | 项目现有江苏日前价格数据 |
| 负荷 | 项目现有负荷数据 |
| 储能 | 4 台 ESS，每台 0.4 MW / 1.6 MWh，接入节点 9、14、17、27 |
| 算法 | MATD3（多智能体，CTDE） |

## 2. 研究的表述边界

本研究是 **江苏日前市场规则下的配电网等值仿真**。

**不得** 宣称：

1. 完整复现江苏省级市场；
2. 复现了江苏省级 SCUC/SCED、分区电价形成或省级安全校核；
3. 项目内部节点价格等于江苏电力交易中心发布的分区价或节点价；
4. 结果构成真实市场的跨日收益实证。

**可以** 宣称：在给定的价格场景、负荷场景与网络模型下，对储能日前报价策略的比较与机制分析。

## 3. 市场范围

只研究 **日前市场（Day-Ahead Market）**。

明确排除：实时市场、实时偏差结算、实时调度、辅助服务市场、AGC 调频、日内滚动交易、日内重新报价。

**不得** 因为现有代码包含实时或滚动机制，就把这些机制带入新研究。现有 `two_settlement`、`clear_rt_rolling`、MPC 滚动窗口都属于历史实现，不构成新研究的默认设计。

## 4. 交易日独立性

每个交易日是 **一个独立 Episode**，含 96 个 15 分钟时段。

- 日内 SOC 连续耦合；交易日之间完全独立。
- 每日初始 SOC 重置为 0.5。
- 不传递跨日 SOC、跨日交易计划、跨日结算状态、未完成的储能义务。
- MATD3 网络参数可以跨日期学习；Replay Buffer 可以存放多个日期的经验，但必须保留 Episode 边界。
- **日终 SOC 不强制等于 0.5。**

## 5. 终端库存价值

必须研究 **有经济依据** 的终端库存价值。

禁止：
- 擅自设定任意残值；
- 把模型库存估值伪装成市场现金收入。

库存价值与现金收益必须在账目上分开记录、分开报告。

## 6. 储能参数（已冻结）

| 项 | 值 |
| --- | --- |
| 台数 | 4 |
| 接入节点 | 9, 14, 17, 27 |
| 单台功率 | 0.4 MW |
| 单台容量 | 1.6 MWh |
| 充放电效率 | 0.92（两侧同） |
| SOC 范围 | [0.10, 0.90] |
| 每日初始 SOC | 0.50 |

改这些参数属于研究设定变更，不属于算法改进。

## 7. 市场机制的表述纪律

1. 市场申报、出清、价格形成和结算应 **尽量遵循江苏当前适用的日前市场规则**。
2. **不能** 把项目自定义假设描述成江苏官方规则。
3. **不能** 把内部成本参数（如循环成本、策略动作上下限）直接当成市场量价申报。
4. **不能** 把 IEEE33 节点局部 LMP 说成江苏全省节点电价。
5. **当日真实日前价格不能提前泄漏给 D-1 申报策略。**

## 8. 结论的证据等级

项目内一切结论使用统一词表（见 `.claude/rules/reporting.md`）：

`PASS` / `FAIL` / `PARTIAL` / `NOT_TESTED` / `INFERRED` / `BLOCKED`。

区分四件事，后者不蕴含前者：代码存在 → 代码运行过 → 测试覆盖且通过 → 科学结论成立。

## 3. 判读

1. **耦合变紧确有可测效应**：随 C 1.5→1.0→0.8，plain matd3 的**价格影响项上升**（scenario-mean power 1.41→1.52→1.54；congestion 行 3.72→4.07→4.15），**消费者增益 cs_d 也上升**（3.03→3.26→3.32；congestion 7.67→8.56）—— 更紧的网络让储能出价在 congestion 产生更多价格影响，同时（新 CS 口径下）消费者支付改善更明显。profit/genuine 对容量变化不敏感（利润主要仍是套利）。
2. **physics-guided critic（M2）并不优于 plain matd3**：三个 C 上 phys 的 profit 均略低（−0.22~−0.33k）、genuine ≈（−0.03~−0.14k）、**cs_d 系统性更低**（−0.43k @1.5、−1.24k @1.0、−0.81k @0.8；congestion @1.0 达 −3.53k）；power 在 1.5 略高、1.0/0.8 略低，无一致方向。**固定 exp-电阻行归一先验没有兑现"显式网络耦合带来收益"的假设** —— 因 critic 已 full-obs（含 LMP/共享特征），该结构先验近似冗余，甚至在消费者侧略损。
3. **回答 RQ3（何时 CTDE/physics 有价值）**：耦合强度（capacity）确实是行为调制器（market power / CS 随 C 变），但"加 physics 先验"本身不带来增益。若要让 centralized 价值显性，更有说服力的对照是 **TD3（独立学习）在同一 C 上** vs matd3 —— 看"协同/集中 critic"的价值随 coupling 增强是否扩大，而非加 physics 网络结构。
4. 训练健康稳定（四条新 run critic loss 有界、无 fell_back；0.8 完全可行）。
